## Abstract

Intelligent Energy Consumption Analytics for Smart Buildings is a data-driven system developed to analyze building energy consumption and provide intelligent insights. The system uses the UCI Appliances Energy Prediction dataset and applies data preprocessing, time-based feature engineering, exploratory data analysis, anomaly detection, and machine learning techniques.

The system identifies energy consumption patterns, detects unusual energy usage using IQR-based anomaly detection, predicts energy consumption using machine learning models, evaluates model performance, identifies important factors influencing consumption, and generates energy-saving recommendations.

The overall objective is to help understand energy usage patterns, identify abnormal consumption, improve energy efficiency, and support informed energy-management decisions.

---

## Project Objectives

The project focuses on:

- Analyzing energy consumption patterns
- Creating time-based features from energy data
- Detecting abnormal energy consumption
- Predicting energy consumption using machine learning
- Comparing machine learning model performance
- Identifying important factors influencing energy consumption
- Generating energy-saving recommendations
- Providing structured analytical results
